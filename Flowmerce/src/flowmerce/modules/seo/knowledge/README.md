Ask Claude) sends all of these files, in file-name order, as cached context. This README is not sent.

To change what Claude knows, edit or replace a file here and restart Flowmerce. Quick, per-brand changes that should not
wait for a file edit go in the **Standing instructions** box in the article editor instead.
